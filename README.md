# Myth

A single-screen puzzle platformer in the spirit of Manic Miner, Technician Ted and Jet Set Willy. Mythology is the theme, played straight and dark. In 1992, music journalist Sally Miller breaks down in a storm and takes shelter in the House of Lost Tales, whose doors open onto nine **Zones**: Greek, Egyptian, Celtic (Irish), Welsh, Anglo-Saxon, Germanic, Finnish, Slavic and Norse. Each zone holds a run of self-contained **Levels**. The full story lives in the Myth Story Bible.

Stack: Vite + vanilla JS + Canvas2D. No framework.

```bash
npm install
npm run dev
```

## What's here so far

- **Level editor**: the page opens straight into it.
- **Test play**: press **P** (or ▶ Test Play) to play the level you're editing, and **Esc** to go back to the editor.
- **Sprite sheets** for Sally Miller and a Skeleton Warrior, generated by `tools/make_sprites.py`.
- **Storm**: rain, lightning (with synthesised thunder in test play), storm-dark skies per zone, dead-tree forests and ground mist. Toggle it in the editor with the Storm checkbox.
- **Fonts**: Almendra for titles, VT323 for the interface and HUD.
- **Greek 1: The Gates of the Underworld**. Collect obols and pay Charon to ferry you across the Styx, gather Persephone's three pomegranate seeds and offer them at the thrones of Hades and Persephone, then get past chained Cerberus to the bronze gates.
- **Greek 2: The Labyrinth of Knossos**. Torchlit darkness, four bronze double axes (labrys) hidden in dead ends, and the Minotaur patrolling the great hall. Ariadne's thread unspools behind Sally and winds back up as she retraces her steps. If the Minotaur tramples it, she must find the glowing loose end, because the way out only opens when the thread is whole.
- **Greek 3: The Field of Ares**, the original test level.

## Editor

| Input | Action |
|---|---|
| Left click / drag | Paint the selected tile, or place the selected entity |
| Right click / drag | Erase (removes the entity under the cursor first, otherwise the tile) |
| Alt + click / middle click | Eyedropper: pick up the tile under the cursor |
| 1–9, 0 | Select tiles in palette order |
| B / R / F | Brush / Rectangle / Flood-fill tool |
| E | Eraser |
| G | Toggle grid |
| Ctrl+Z / Ctrl+Y (or Ctrl+Shift+Z) | Undo / redo |
| P | Test play |

Clicking a Skeleton again with the Skeleton tool flips its starting direction.

Everything autosaves to `localStorage`. When the starter set gains new levels, they're added to your saved project automatically (matched by name), without touching anything you've made. **Export all** downloads the whole project as `myth-levels.json`. Copy that file over `src/levels/starter.json` and it becomes the default set that ships with the game. **Reset all** throws away the local copy and reloads that file.

## Rules (test play)

- ←/→ or **O/P** to move, **Space** to jump, ↑/↓ or **Q/A** to climb ladders. **R** restarts.
- Jumps follow a fixed arc and the direction is locked at take-off. Walking off a ledge drops you straight down.
- Falling more than 8 tiles kills you (`PHYSICS.fatalFallTiles` in `src/config.js`; set it to 0 to turn this off).
- Collect every relic to open the exit portal, then walk into it.
- Water and skeletons kill you, and the screen resets.

## Tiles

| Code | Tile | Behaviour |
|---|---|---|
| `g` | Grass | Platform: stand on it, jump up through it |
| `m` | Mud | Crumbles after you've stood on it for half a second |
| `s` | Sand | Platform |
| `w` | Swamp | Platform that slows you down |
| `d` | Dirt | Solid on every side |
| `~` | Water | Deadly |
| `l` | Grey Water | Deadly: the water of forgetting (Lethe) |
| `=` | Wood | Plank platform |
| `M` | Marble | Platform: palace balconies |
| `H` | Ladder | Climbable. The top rung can be stood on |
| `T` | Tree | A dead tree. Its top tile's branches are a platform |
| `#` | Stone | Solid wall |
| `o` | Obsidian | Solid wall: the halls of Hades |
| `K` | Labyrinth Wall | Solid ochre ashlar; some blocks carry a double-axe mason's mark, as at Knossos |
| `C` | Minoan Column | Decoration: red, tapering downwards, with a black capital |
| `Y` | White Cypress | Decoration: marks the spring of Lethe |

Ground tiles draw as thin 8px ledges unless more ground is stacked below them, which gives the classic Manic Miner look. Grass only grows on exposed tops.

**Adding a tile:** add an entry to `TILES` in `src/tiles.js` with an unused single-character code, a behaviour and a `draw()` function. The editor palette picks it up automatically.

## Level format

## Entities

| Entity | Size | What it does |
|---|---|---|
| Sally start | 1×2 | Where Sally begins |
| Exit | 2×2 | Opens when the level is solved. Click again to switch between the temple doorway and the bronze gates |
| Thrones | 3×2 | Hades and Persephone. Bring every seed here to unseal the exit |
| Charon's ferry | 3×1 | Place it just above water; it sails the full width of that water. Stand on the deck with an obol and Charon takes you across |
| Torch | 1×1 | A wall torch: a pool of light in torchlit levels |
| Relic | 1×1 | Collect them all |
| Labrys | 1×1 | The bronze double axe. Collect them all |
| Pomegranate seed | 1×1 | Offer them at the thrones (or, with no thrones, just collect them) |
| Obol | 1×1 | Charon's fare: one per crossing |
| Skeleton | 1×2 | Patrols left and right, turning at walls and ledge ends |
| Shade | 1×2 | Drifts up and down through platforms, turning at solid tiles or the screen edge |
| Minotaur | 2×2 | Patrols his floor. When Sally is ahead of him on the same level with no wall between (9 tiles), he paws the ground, then charges until he hits a wall (stunned for 1⅔ seconds) or runs out of floor. Tramples Ariadne's thread |
| Cerberus | 2×2 | Chained to his stake (3 tiles of chain). Lunges only when Sally moves towards the exit within his reach, then pads back and rests for 2½ seconds. Jump over him while he sleeps |

The editor draws each ferry's route and Cerberus's chain reach on the level. Each level also has a **Setting**: outdoor storm; underworld, with no sky and rising embers; or labyrinth, which is torchlit darkness with Ariadne's thread tied to the exit, and a **Keeper's note** shown on its title card.

## Level format

Levels are plain JSON, so they diff nicely in git:

```json
{
  "name": "The Field of Ares",
  "tiles": ["................................", "..."],
  "entities": [
    { "type": "spawn", "c": 3, "r": 18 },
    { "type": "skeleton", "c": 12, "r": 18, "dir": 1 }
  ]
}
```

There are 20 rows of 32 tile codes. An entity's `c`/`r` is the cell its feet stand in. The exit is 2×2, and its anchor is the bottom-left cell.

## Sprites

```bash
python3 tools/make_sprites.py   # needs Pillow
```

This writes `public/sprites/<name>.png` plus `<name>.json`, which holds frame size and the animation rows. Frames are 24×32 and face right; the game mirrors them for left. Enlarged previews go in `tools/preview/`.

- **sally**: idle (2), walk (4), jump, fall, climb (2)
- **skeleton**: walk (4), attack (3), collapse (5). Play collapse backwards for a "rise from the earth" effect.
- **charon**: idle (2), pole (4)
- **shade**: drift (4), translucent
- **minotaur**: walk (4), paw (2), charge (4), stunned (2). Frames are 32×36: a bull's head on a man's body, in a Minoan kilt
- **cerberus**: idle (2), run (4), rest (1). Frames are 44×28, with three heads and a serpent for a tail, after Apollodorus

The skeleton is drawn as a bone rig: limbs are lines from joint angles, and the skull and crest are small bitmaps. A new pose is just a new set of angles.
